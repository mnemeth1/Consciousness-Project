# Evidence records

These project-authored ledgers preserve stable IDs, source locators, epistemic types, competing explanations, dependence groups and limitations. They contain bibliographic information and project analysis; source documents are excluded.

- `sources.json`: 173 bibliographic/source records, including exact-version and access limits.
- `claims.json`: 717 claims, each labeled by type and reviewed scope.
- `arguments.json`: 124 argument reconstructions with premises, objections, replies and unresolved issues.
- `cases.json`: 23 case/study records with chronology, denominators and dependence information.
- `review_summaries.json`: selected fields from 35 canonical review records. Full internal review evidence and hash maps are omitted.

These counts are record counts, not numbers of independent sources, samples or verified events. The ledgers include accepted Phase 2 contributions; the current reviewed cumulative report remains Version 1. Consult [current status](../STATUS.md) for unfinished synthesis and review work, and [publication notes](../PUBLICATION_NOTES.md) for redaction and audit limits.
